# TSSR · Mon espace de révision
Site MkDocs Material, mis en ligne automatiquement sur GitHub Pages à chaque push sur `main`.

1. Crée le dépôt `tssr-cours` et envoie tout le contenu de ce dossier.
2. **Settings → Pages → Source : GitHub Actions**.
3. Remplace `TON-PSEUDO` dans `mkdocs.yml` (`site_url`, `repo_url`).
4. Le site est sur `https://TON-PSEUDO.github.io/tssr-cours/`.

Ajout de contenu : voir `docs/ajouter.md`.
